## 🤔 書く前に① 相手の子を、メソッドに渡す

これまでのメソッドは、`piko.eat(3)` のように「数字」を受け取っていたね。
でも、メソッドは **モンスター（相手の子）** を受け取ることもできるんだ。

```python
piko.play_with(momo)      # ピコ、モモと遊んで！
```

```python
def play_with(self, other):
    ...
```

第05章の読みかえを思い出そう。Pythonは、こう読みかえるよ。

```text
piko.play_with(momo)
   ↓ Pythonの頭の中
Monster.play_with(piko, momo)

def play_with( self ,  other ):
                 │       │
               ピコ     モモ
```

**ドットの左の子が `self`、カッコの中の子が `other`** に入る。
メソッドの中に、**2匹のモンスターが同時に登場する** んだ。

`momo.play_with(piko)` と書けば、今度は `self` がモモ、`other` がピコになる。
役わりは、呼び方で入れかわるよ。

> 💡 `other` は「ほかの」という意味の英語。`self`（自分）と対になる名前として、よく使われるよ。

## 🧩 書く前に② 渡すのは「名前」ではなく「本人」

```python
piko.play_with("モモ")   # ❌ 名前（文字）を渡した
piko.play_with(momo)     # ⭕ モモ本人を渡した
```

`"モモ"` は、ただの文字。HP も、`play()` も持っていない。
`momo` は、第07章で話した **モモ本人を指す名札**。だから HP も `play()` も持っている。

「モモ」と書いた紙を広場に連れていっても、遊んでくれないよね。
**メソッドに渡すのは、名札（本人）** だよ。

それに、`other` はモモの **コピーではない**。
メソッドの中で `other.play()` すると、**本物のモモ** が遊んで、本物のモモの HP が減るんだ。

---

## 🔍 書く前に③ 相手の値は、相手のメソッドに頼む

この章でいちばん大事なところ！ 👀

審判は、相手の HP を外から直接書きかえていた。

```python
target.hp = target.hp - damage          # ❌ 外から直接さわる
```

この章のファイルには、お手本のメソッド `take_damage` が用意されているよ。

```python
def take_damage(self, amount):
    """ダメージを受ける。HP は 0 より小さくならない。本当に減った量を返す。"""
    before = self.hp
    self.hp = self.hp - amount
    if self.hp < 0:
        self.hp = 0
    return before - self.hp
```

これを使えば、こう書ける。

```python
lost = target.take_damage(damage)       # ⭕ 相手のメソッドに頼む
```

`take_damage` の中には、**「0 より小さくしない」というルール** が入っている。
相手に頼めば、ルールはかならず守られるんだ。

> 🍱 たとえば給食当番。友だちのおぼんに、勝手におかずを山もりにしたりしないよね。
> 「はい、どうぞ」と渡して、**受け取るのは本人**。その方が、こぼれたりしない。

> ⚠️ 正直に言うと、Pythonは `target.hp = -2` と直接書くことを **禁止はしない**。
> だから、これは「みんなで守る **約束**」なんだ。
> 約束を守っていれば、ルールは1か所（メソッドの中）にあるだけでいい。
> ルールを直したい時も、その1か所を直すだけで済むよ。

### `take_damage` は、本当に減った量を返す

HP が 4 の子に 6 ダメージを与えると、HP は 0 で止まる。
**本当に減ったのは 4** だね。`take_damage` は、その 4 を `return` するよ。
第05章で、`is_tired()` が答えを `return` したのと同じ形だよ。

## 🔍 書く前に④ 確かめてから、動く

ふたり遊びには、広場のルールがあるよ。

| ルール | どうする？ |
|---|---|
| 自分自身（同じ本人）とは遊べない | お休み（`False`） |
| どちらかがつかれていたら、遊ばない | お休み（`False`） |
| ふたりとも元気なら | 自分も相手も、それぞれ `play()` する（`True`） |

大事なのは **順番**。遊ぶ前に、ふたりとも確かめる。

```python
self.play()                  # ❌ 先に遊んでしまうと……
if other.is_tired():
    return False             # 「お休み」なのに、自分だけつかれてしまう！
```

だからこの章では、**確かめる係**（`can_play_with`）と **遊ぶ係**（`play_with`）に、
メソッドを分けて書くよ。

## 📇 ことばカード

| ことば | 意味 | この章では |
|---|---|---|
| `other` | メソッドに渡された **相手の子**（本人） | `piko.play_with(momo)` の モモ |
| 相手に頼む | 相手の値は、相手のメソッドで変える | `other.take_damage(5)` |
| 本当に減った量 | `take_damage` が返す数 | HP 4 に 6 ダメージ → 4 |
| `or` | どちらか1つでも `True` なら `True` | `self.is_tired() or other.is_tired()` |

## 💡 書いた後に: 何が起きたの？

### `piko.play_with(momo)` を追いかけよう

```text
piko.play_with(momo)            self = ピコ、other = モモ
 ├ self.can_play_with(other)     ピコとモモ、ふたりの元気を確かめる → True
 ├ self.play()                   ピコが遊ぶ（play の中の self は ピコ）
 └ other.play()                  モモが遊ぶ（play の中の self は モモ！）
```

`other.play()` を呼ぶと、`play` の中の `self` は **モモ** になる。
同じ `play` メソッドなのに、だれに頼むかで、遊ぶ子が変わる。第05章で見た仕組みが、ここでも働いているよ。

### 事件の解決: 相手の HP は、相手が変えた

運動会の最後の一撃を思い出そう。

```text
💥 スラ太 の たいあたり！ ドラン に 2 ダメージ  こうかは ばつぐんだ！
   （ドラン の HP は 2 しかなかった！）
   ドラン HP ░░░░░░░░░░ 0/10
```

強さは 5 なのに、ダメージは 2。そして HP は 0 でピタッと止まった。
スラ太は、ドランの HP を自分で計算していない。
**`other.take_damage(power)` で、ドラン自身に頼んだ** から、ルールが守られたんだ。

### 「頼む」と、ルールが1か所で済む

もし運動会で、たいあたり・頭つき・しっぽ……と技が増えても、
どの技も `other.take_damage(...)` に頼めば、HP のルールは `take_damage` の中の **1か所だけ**。
審判のように外から直接書いていたら、技の数だけルールを書かないといけなくなる。

これが、オブジェクト同士が **「相手に頼む」** ことの、いちばんのよさだよ。🙌
