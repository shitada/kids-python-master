# 🎮 課題04: ピクセル・メロディ・クエスト　難しさ ★★★★

> **音の森を救え！**

音の森から、色とメロディが盗まれてしまった！
主人公の **ピコ**を動かして、7体の **音符の精霊**を集めよう。
ノイズモンスターをかわし、最後の演奏に成功すると、
森に色と音が戻るよ。🌈🎵

この課題には **12個のミッション**があります。
`pixel_melody_quest.py`にある `TODO 01`から `TODO 12`までを、
順番に直してゲームを完成させよう！

---

## ⚠️ 始める前に

この課題では、自分のパソコン上にゲーム画面を開きます。
**CodespacesやDev Containerの中ではなく、手元のパソコンの
VS CodeとPythonで実行してください。**

初めての時は、このリポジトリのフォルダで次を実行します。

```bash
python -m venv .venv
```

次に、作ったPython環境を有効にします。

```bash
# Windows
.venv\Scripts\activate

# Mac
source .venv/bin/activate
```

必要なライブラリを入れます。

```bash
pip install -r requirements.txt
```

ゲームを始めるコマンド:

```bash
python challenges/04-pixel-melody-quest/pixel_melody_quest.py
```

## 🕹️ 遊び方

| キー | 操作 |
|---|---|
| `↑` `↓` `←` `→` または `W` `A` `S` `D` | ピコを動かす |
| `Space` | メロディの木で演奏する |
| `R` | クリア後にもう一度遊ぶ |
| `Esc` | ゲームを終了する |

### ゲームのゴール

1. 森にいる `DO RE MI FA SO LA SI`の7体を集める
2. ノイズモンスターに注意して、画面上の **メロディの木**へ行く
3. 合図に合わせて `Space`を押し、8拍のうち6回成功する
4. `CLEAR!`が出たら大成功！🏆

モンスターにぶつかるとハートが減ります。
ハートがなくなっても、**集めた音符はそのまま**なので、
あきらめずに続けられるよ。

## 🧠 オブジェクト指向とは？

ゲームには、ピコ、精霊、モンスター、メロディの木など、
色々な「物」が出てきます。

オブジェクト指向では、それぞれの物に
**「自分の仕事は自分に任せる」**ようにプログラムを作ります。

| 言葉 | このゲームでは |
|---|---|
| クラス | ピコやモンスターを作る **設計図** |
| インスタンス | 設計図から実際に作った1体 |
| 属性 | 位置、色、ハートなど、その物が **覚えている情報** |
| メソッド | `move()`や `draw()`など、その物が **できること** |
| `self` | 「このピコ」「このモンスター」のように、自分自身を指す |

難しい言葉は[用語集](../../GLOSSARY.md)でも確認できます。

## 🚀 12個のミッション

### 01 📦 物の基本設計図

`Actor.__init__()`を直して、位置・大きさ・色を
`self.rect`と `self.color`に覚えさせよう。

- **学ぶこと:** クラス、`__init__`、`self`、属性
- **完成の目印:** 画面下に小さなピコが現れる
- **ヒント:** `pygame.Rect(x, y, width, height)`は、位置と大きさをまとめた箱

### 02 🐣 ピコを生み出す

`Player`は `Actor`の仲間です。`super().__init__()`を使って、
元の設計図からピコを作ろう。

- **学ぶこと:** 継承、`super()`
- **完成の目印:** ピコが42×48の大きさになる
- **ヒント:** コメントにある `super().__init__(...)`をよく見よう

### 03 🎨 ピコをドット絵にする

`Player.draw()`で、課題01のような二次元リストを絵に変えよう。
元の四角い姿から、水色のドット絵に変身させよう。

- **学ぶこと:** メソッド、オーバーライド
- **完成の目印:** ピコに顔と手足ができる
- **ヒント:** `draw_pixel_grid()`には、画面・設計図・色・位置を渡す

### 04 👟 ピコを歩かせる

`Player.update()`で、今押されているキーを調べよう。
キーに合わせて `dx`と `dy`を変えると、ピコが動きます。

- **学ぶこと:** オブジェクトの属性をメソッドで変える
- **完成の目印:** 矢印キーかWASDでピコを動かせる
- **ヒント:** 左と上はマイナス、右と下はプラス

### 05 🌳 森の外へ出ないようにする

`keep_in_forest()`に、ピコを画面の中へ戻す処理を書こう。
動く仕事を小さなメソッドに分けるのも大切です。

- **学ぶこと:** 1つのメソッドに1つの仕事を任せる
- **完成の目印:** 端へ行ってもピコが消えない
- **ヒント:** `Rect`の `clamp_ip()`は、大きい四角の中へ戻してくれる

### 06 🎵 音符の精霊の設計図

`NoteSpirit.__init__()`で、名前・周波数・色・位置・
集めたかどうかを覚えさせよう。

- **学ぶこと:** 1つのクラスに複数の属性を持たせる
- **完成の目印:** 森に1体の音符が浮かぶ
- **ヒント:** 最初はまだ集めていないので `collected = False`

### 07 🌈 7体の精霊を呼び出す

`make_note_spirits()`で、`NOTE_SPECS`のデータから
7つの `NoteSpirit`インスタンスを作ろう。

- **学ぶこと:** 同じクラスから、違うインスタンスを複数作る
- **完成の目印:** 7色の音符が森にそろう
- **ヒント:** `for name, frequency, color, position in NOTE_SPECS`

### 08 🤝 精霊を仲間にする

`collect_touching_note()`で、ピコと精霊の四角が
ぶつかったか調べよう。ぶつかったら、その精霊の `collect()`を呼びます。

- **学ぶこと:** 2つのオブジェクトがメソッドで協力する
- **完成の目印:** 触れた音符が消え、`NOTES`の数が増える
- **ヒント:** `player.rect.colliderect(note.rect)`で、ぶつかったか分かる

### 09 👾 ノイズモンスターを動かす

`NoiseMonster.update()`で、モンスターを `velocity`の値だけ動かそう。
画面の端に来たら、`velocity`の正負を反対にします。

- **学ぶこと:** 各インスタンスに自分で動いてもらう
- **完成の目印:** 4体のモンスターが違う速さで動く
- **ヒント:** 反対の数にするには `*= -1`

### 10 ❤️ ダメージと無敵時間

`handle_noise_hit()`で、ピコとモンスターの当たり判定を行い、
`player.take_damage(now)`を呼ぼう。

- **学ぶこと:** ハートや無敵時間のような「状態」
- **完成の目印:** ぶつかるとハートが減り、ピコがしばらく点滅する
- **ヒント:** ダメージを受けたら、すぐ `True`を返す

### 11 🥁 1拍の長さを作る

`RhythmChallenge.__init__()`で、BPMから1拍の
ミリ秒を計算しよう。課題02の計算が再び登場！

- **学ぶこと:** オブジェクトが時間とスコアを覚える
- **完成の目印:** BPM 100なら `beat_ms`が600になる
- **ヒント:** 1分は `60_000`ミリ秒

### 12 🎼 ゲーム監督に全員をつなげる

`Game.update()`で、今が探索中か演奏中かを調べ、
各オブジェクトへ仕事をお願いしよう。

- **学ぶこと:** コンポジション、状態の切り替え、仕事の委譲
- **完成の目印:** 最後の演奏が動き、`CLEAR!`までたどり着ける
- **ヒント:** `if self.state == EXPLORE:`と `elif self.state == RHYTHM:`

## 🌟 発展チャレンジ

- `PLAYER_GRID`と `PLAYER_PALETTE`を変えて、自分の主人公を作る
- `NOTE_SPECS`の位置や色を変えて、森を作り変える
- `BPM`を `80`や `140`にして、演奏の速さを変える
- `MELODY`の並びを変えて、自分のメロディを作る
- `NoiseMonster`を増やしたり、`velocity`を変えたりする
- `Player`に新しいメソッドを作り、ダッシュできるようにする

## 🆘 困った時は

| 困ったこと | 解決方法 |
|---|---|
| `No module named 'pygame'` | このページの「始める前に」を見て、`pip install -r requirements.txt`を実行 |
| ゲーム画面が出ない | CodespacesやContainerではなく、手元のPCのPythonで実行 |
| `SILENT MODE`と出る | 音は出ないが、ゲームはそのまま遊べる |
| ピコが動かない | TODO 04の `dx`と `dy`、保存したかを確認 |
| 演奏が進まない | TODO 11とTODO 12を確認 |
| 画面を閉じられない | `Esc`キーを押す |
