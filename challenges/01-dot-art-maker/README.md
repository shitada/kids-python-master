# 🎨 かだい01: ドットえメーカー　むずかしさ ★☆☆

**すうじの ならび** を **いろ** に かえて、じぶんだけの え（PNGがぞう）を つくろう！

## 🎯 この かだいで できるように なること
- 二次元リスト（リストの なかの リスト）で ますめを あらわす
- 二重ループ（for の なかの for）で ますめを ぜんぶ しらべる
- じしょ（すうじ → いろ）を つかう

---

## 🧩 しくみ

`grid`（ますめ）の すうじは、`palette`（いろの ひょう）の ばんごうだよ。

```
palette = { 0:しろ, 1:くろ, 2:あか, 3:きいろ, 4:みずいろ, 5:みどり }

grid の 2 → palette の 2 → あか の 四角を ぬる！
```

### いろの ばんごう ひょう

| ばんごう | いろ |
|:---:|:---|
| 0 | ⬜ しろ |
| 1 | ⬛ くろ |
| 2 | 🟥 あか |
| 3 | 🟨 きいろ |
| 4 | 🟦 みずいろ |
| 5 | 🟩 みどり |

---

## 🚀 やってみよう

1. `dot_art.py` を ひらく
2. `# TODO` の ところを、ヒントを みながら かく
3. ▷ ボタン（または `python dot_art.py`）で じっこう
4. できた **`art.png`** を クリックして みてね！

うまく いかない ときは、`answer/dot_art.py`（こたえ）を みてもOK。
でも、まずは じぶんで チャレンジ！💪

---

## 🌟 はってん チャレンジ

- `grid` の すうじを かえて、**じぶんの え** を つくろう（かお・きのこ・ほし…）
- `palette` に あたらしい いろを ふやそう（`6: (255, 130, 200)` みたいに）
- じぶんの なまえの さいしょの もじを、ドットえで かいてみよう！

### お手本 grid（コピーして つかってね）

**にっこりフェイス 😊**
```python
grid = [
    [0, 3, 3, 3, 3, 3, 0],
    [3, 3, 1, 3, 1, 3, 3],
    [3, 3, 3, 3, 3, 3, 3],
    [3, 1, 3, 3, 3, 1, 3],
    [3, 3, 1, 1, 1, 3, 3],
    [0, 3, 3, 3, 3, 3, 0],
]
```

> 💡 ヒント: `grid` の どの ぎょうも、**おなじ ながさ**（おなじ かずの すうじ）に してね。
