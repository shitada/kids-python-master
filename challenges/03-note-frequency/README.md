# 🎸 かだい03: ドレミ→しゅうはすう けいさんき　むずかしさ ★★★

「ドレミファソラシド」の おとは、じつは **すうじ（しゅうはすう）** で あらわせるよ。
おとの たかさを けいさんする きかいを つくろう！🎸

## 🎯 この かだいで できるように なること
- じしょ（おとの なまえ → はんおんの かず）を つかう
- かんすう（なまえを いれると しゅうはすうを かえす）を つくる
- すうしき・べきじょう `**` を つかう
- 「1オクターブ たかいと しゅうはすうは 2ばい」の ひみつを しる

---

## 🧩 しくみ（おんがくの ひみつ）

- きじゅんの おと **ラ（A4）= 440 Hz**（ヘルツ）。
- おとは 1オクターブ たかく なると、しゅうはすうが **ちょうど 2ばい** になる。
- 1オクターブ = **12この はんおん** に わけられる（平均律）。
- だから、1はんおん あがると しゅうはすうは `2 の (12ぶんの1) じょう` ばいに なる。

**けいさんの しき:**
```
しゅうはすう = 440 × (2 ** (はんおんの かず ÷ 12))
```

「ラ」から なんはんおん はなれているか（`semitones`）を つかって けいさんするよ。

