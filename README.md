## 🚀 はじめかた

### ① ブラウザだけで はじめる（Codespaces・いちばん かんたん）

1. このページの みどりの **「Code」** ボタンを おす
2. **「Codespaces」** タブを えらぶ
3. **「Create codespace on main」** を おす
4. すこし まつと、ブラウザの なかに **VS Code（コードを かく がめん）** が ひらくよ
5. じゅんびが おわると、じぶんの パソコンに なにも いれなくても Python が うごく！✨

> 💡 つかいおわったら、Codespaces の ページで **Stop（ていし）** しておくと むだづかいに ならないよ。

### ② じぶんの パソコンの VS Code で はじめる

**ほうほうA（おすすめ・かんたん）**
1. VS Code に かくちょうきのう **「Dev Containers」** を いれる
2. この フォルダを ひらいて **「Reopen in Container」** を えらぶ
   → Codespaces と おなじ かんきょうが じどうで できあがる

**ほうほうB（じぶんで じゅんび する）**
```bash
python -m venv .venv
# Windows の ひと:
.venv\Scripts\activate
# Mac の ひと:
source .venv/bin/activate

pip install -r requirements.txt
```

## 🎮 かだいの やりかた（3ステップ）

どの かだいも やることは おなじ！

1. **① ひらく** … ひだりの ファイル いちらんから、やりたい かだいの `.py` ファイルを クリック
2. **② じっこう** … みぎうえの **▷（さんかく）ボタン** を おす
   （または したの ターミナルで `python ファイル名.py` と うつ）
3. **③ みる** … できた え（`.png`）は、ファイル いちらんで クリックすると みられるよ！

> 📝 かならず **ほぞん（Ctrl+S / Cmd+S）してから じっこう** してね。

## 🆘 こまったときは

| こまったこと | どうする？ |
|-------------|-----------|
| ▷（じっこう）ボタンが ない | VS Code に **Python かくちょうきのう** を いれよう（`ms-python.python`） |
| え が でてこない | **ほぞんしてから** もういちど じっこうしたか かくにん |
| `ModuleNotFoundError: Pillow` と でる | ターミナルで `pip install -r requirements.txt` を うつ |
| もじが へんに なる（ローカルの Windows） | VS Code の したの ターミナルを つかえば だいじょうぶ（UTF-8） |
