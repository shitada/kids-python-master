## 🚀 始め方

### ① ブラウザだけで始める（Codespaces・課題01〜03）

1. このページにある緑色の **「Code」** ボタンを押す
2. **「Codespaces」** タブを選ぶ
3. **「Create codespace on main」** を押す
4. 少し待つと、ブラウザの中に **VS Code（コードを書く画面）** が開く
5. 準備が終わると、自分のパソコンに何も入れなくても Python が動く！✨

> 💡 使い終わったら、Codespacesのページで **Stop（停止）** しておくと使い過ぎを防げるよ。
>
> ⚠️ **課題04のpygameゲーム**は、Codespacesでは画面を開けません。
> 課題04だけは、次の「自分のパソコン」で実行してね。

### ② 自分のパソコンの VS Code で始める

**方法A（課題01〜03・おすすめ）**
1. VS Codeに拡張機能 **「Dev Containers」** を入れる
2. このフォルダを開いて **「Reopen in Container」** を選ぶ
   → Codespacesと同じ環境が自動で用意される

**方法B（課題04にも対応・自分で準備する）**
```bash
python -m venv .venv
# Windowsの人:
.venv\Scripts\activate
# Macの人:
source .venv/bin/activate

pip install -r requirements.txt
```

> 🎮 課題04は **Reopen in Containerをせずに**、手元のパソコンの
> Pythonで `pixel_melody_quest.py`を実行します。

## 🎮 課題の進め方（3ステップ）

どの課題も進め方は同じ！

1. **① 開く** … 左側のファイル一覧から、取り組みたい課題の `.py` ファイルをクリック
2. **② 実行** … 右上の **▷（三角）ボタン** を押す
   （または、下のターミナルで `python ファイル名.py` と入力する）
3. **③ 見る・遊ぶ** … `.png`やターミナルの結果を確認する。
   課題04では、開いたゲーム画面で遊ぼう！

> 📝 必ず **保存（Ctrl+S / Cmd+S）してから実行** してね。

## 🆘 困ったときは

| 困ったこと | 解決方法 |
|-------------|-----------|
| ▷（実行）ボタンがない | VS Codeに **Python拡張機能** を入れよう（`ms-python.python`） |
| 絵が出てこない | **保存してから**、もう一度実行したか確認する |
| `ModuleNotFoundError: Pillow` と表示される | ターミナルで `pip install -r requirements.txt` と入力する |
| `ModuleNotFoundError: pygame` と表示される | 手元のパソコンで `pip install -r requirements.txt` と入力する |
| 課題04のゲームが開かない | CodespacesやContainerではなく、手元のパソコンのPythonを使う |
| 文字が正しく表示されない（ローカルの Windows） | VS Codeの下にあるターミナルを使えば大丈夫（UTF-8） |
